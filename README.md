# 幼儿行为观察助手

上传幼儿园活动视频，本机运行的 Qwen3-VL-8B 会逐段记录幼儿行为，再生成一份观察记录表草稿（观察目的、观察实录、行为分析解读、支持策略、教师分析反思）。可以在网页上直接修改，然后打印、存为 PDF 或下载 Word。

视频只在这台电脑上处理，不会上传到任何外部服务器；分析完成后，上传的视频和抽出的画面会自动删除。

## 电脑配置

- Windows 10 / 11
- 推荐 NVIDIA 显卡，显存 8GB 及以上。显存不足或没有独立显卡也能运行，但会慢很多，可以换用更小的模型（见下方"常见问题"）。
- 内存 16GB 及以上，硬盘剩余空间 10GB 以上。

## 安装（只需一次）

1. 安装 **Python 3.10 或更新版本**：https://www.python.org/downloads/
   安装界面第一页**务必勾选 "Add python.exe to PATH"**。
2. 安装 **Ollama**：https://ollama.com/download/windows
   安装后它会在后台运行，右下角托盘里能看到羊驼图标。
3. 双击 **`install.bat`**。它会安装依赖（使用清华镜像），并下载模型 `qwen3-vl:8b-instruct`（约 6GB）。

## 使用

双击 **`start.bat`**，浏览器会自动打开 http://127.0.0.1:8000 。使用期间不要关闭黑色的命令行窗口。

1. 上传视频。
2. 填写观察信息。其中"外貌特征"一栏很重要，例如"穿黄色上衣、戴眼镜的男孩"，AI 靠它在画面里找到要观察的孩子。
3. 点击"开始分析"，左下方会实时显示逐条记录，点击时间可以跳到视频对应位置。
4. 分析完成后，核对并修改右侧的记录表，然后打印或下载。

**AI 生成的只是草稿。** 它可能看错或漏看，请老师对照视频核对，尤其是"行为分析解读"和"教师分析反思"部分。

## 工作原理

1. 视频按 30 秒切段，每 2 秒抽一帧（最长边 448 像素）。
2. 每段画面连同时间标签一起交给模型，模型按"时间｜对象｜行为"逐条写出客观记录。
3. 所有记录汇总后，再让模型撰写记录表正文。如果整段视频没有记录到行为，就不会生成分析，以免 AI 编造内容。

## 常见问题

**太慢或显存不够**：打开 `config.py`，把 `MODEL_NAME` 改成 `qwen3-vl:4b-instruct`，然后在命令行运行 `ollama pull qwen3-vl:4b-instruct`。也可以把 `FRAME_INTERVAL` 调大（比如 3），减少抽帧数量。

**提示"连接不上 Ollama"**：从开始菜单打开 Ollama，等托盘出现图标后再试。

**为什么不用 `qwen3-vl:8b`**：这个名字默认指向 thinking（思考）版，会先输出很长的思考过程，又慢又容易超出字数限制。instruct 版直接给出结果。

## 文件说明

- `app.py`：网页后端和分析流程
- `model.py`：调用 Ollama
- `prompts.py`：两段提示词，想调整记录风格就改这里
- `video.py`：切段抽帧（使用 imageio-ffmpeg 自带的 ffmpeg）
- `config.py`：模型名称、抽帧间隔等参数
- `static/index.html`：网页
